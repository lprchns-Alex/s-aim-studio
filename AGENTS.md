# Project storage and publishing rules

- Store and version this project in GitHub. The user has explicitly authorized GitHub Pages for sharing the finished website.
- Approved public URL: https://lprchns-alex.github.io/s-aim-studio/ru/. Publish updates via the Pages workflow.
- Do not publish or deploy to Sites, chatgpt.site, or any OpenAI/Codex-branded domain.
- Do not enable GitHub Pages or another hosting service unless the user explicitly requests publication and agrees to the destination.
- Use local previews when checking changes. Preserve existing version history.
- Contacts remain demo placeholders until the user supplies real details.

## Design versions

- Original approved design remains in dist/index.html and dist/ru/index.html; do not overwrite it when working on v2.
- New design lives under dist/v2/. Share https://lprchns-alex.github.io/s-aim-studio/v2/ru/ for the redesign.
- Reuse current bilingual text from tools/v2-content.json. Do not invent customers, results, or employee identities.
